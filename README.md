# 📖 Overview

Delivery Time Predictor is a machine learning web application that estimates the delivery time of food orders based on user-provided delivery information.

The application combines a trained machine learning model with a Flask web interface, allowing users to enter delivery details and receive real-time delivery time predictions through an interactive browser-based application.

The project demonstrates the complete machine learning workflow from data preprocessing and model training to web integration and cloud deployment.

# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/Mytresh-gowd/delivery-time-predictor.git
```

Move into the project

```bash
cd delivery-time-predictor
```

Create a virtual environment

```bash
python -m venv venv
```

Activate the environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000/
```

# 🎯 Application Workflow
